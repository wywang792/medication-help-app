# Tabbar 图标说明

此目录需要放置以下 tabbar 图标文件：

## 需要的图标文件

1. **首页图标**

   - `home.png` - 首页未选中状态图标
   - `home-active.png` - 首页选中状态图标

2. **积分商城图标**

   - `mall.png` - 积分商城未选中状态图标
   - `mall-active.png` - 积分商城选中状态图标

3. **我的图标**
   - `profile.png` - 我的未选中状态图标
   - `profile-active.png` - 我的选中状态图标

## 图标要求

- 尺寸：建议 81x81 像素
- 格式：PNG 格式，支持透明背景
- 颜色：
  - 未选中状态：灰色 (#7A7E83)
  - 选中状态：蓝色 (#007AFF)

## 临时解决方案

如果暂时没有图标文件，可以：

1. 使用在线图标生成器创建
2. 从图标库下载（如 iconfont、Feather Icons 等）
3. 使用简单的占位图片

注意：图标文件缺失会导致 tabbar 显示异常，请确保所有图标文件都存在。
